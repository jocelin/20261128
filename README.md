# 台北換你翻（街頭展示頁）

**線上展示：<https://jocelin.github.io/20261128/>**

單一檔案的展示頁，適合用 iPad 或手機橫向全螢幕舉牌。**個人支持用，非任何陣營的官方文宣。**

## 使用
- 預設：「BC 翻盤了 10/24 → 台北 ③ 換你翻!」，可用左下角按鈕切換中文／英文。
- 左下角鉛筆：自訂小標、主標（每行 5 字內）、貼紙、圖示，並可切換飛機航線；按「複製／分享連結」產生帶參數的網址。
- 參數：`tag`（小標）、`d`（貼紙）、`m1`／`m2`（主標兩行）、`ic`（表情符號圖示）、`pl`（1／0，飛機航線）。`pl`＝1 開啟、0 關閉飛機航線（自訂版預設關閉，需加 `pl=1` 才會顯示）。
- 範例：[從東京回來・台北 順順投（日本國旗＋飛機）](https://jocelin.github.io/20261128/?tag=%E5%BE%9E%E6%9D%B1%E4%BA%AC%E5%9B%9E%E4%BE%86&m1=%E5%8F%B0%E5%8C%97&m2=%E9%A0%86%E9%A0%86%E6%8A%95&ic=%F0%9F%87%AF%F0%9F%87%B5&pl=1)
- 英文預設可加 `#en`。進入全螢幕後，所有控制項會隱藏。
